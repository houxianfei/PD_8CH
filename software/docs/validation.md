## 基于AFS v1.3.0的历史性能验证

高精度限帧、八通道65k缓存受控渲染基准、1500点快照边界和完整缓存读取均已验证。数据未变化的图复用Power/极值缓存；实时数据版本变化时重新计算。CSV按需读取完整缓存。旧限帧等待约30.88ms，新限帧约16.67ms；详细结果与测试边界见performance.md。未用computer use，没有实物板卡或实际可见窗口帧率实测。
